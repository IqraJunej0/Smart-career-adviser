# Jobs and skills recommendation system 

Name : Iqra Junejo.
Instructor : Chandni Talpur.
Project: Jobs and skills recommendation system.
Institute: The Sufi Institute, Lauri Shareef Badin.

The Job & Skill Recommendation System is a C++ programming project designed to help students and job seekers find suitable career opportunities based on their education, skills, interests, and experience. The system analyzes the user's skills and recommends suitable careers, jobs, and courses. It also identifies missing skills and provides a learning roadmap to help users improve their qualifications. Additionally, it includes user login, job applications, CV generation, and an admin panel.
